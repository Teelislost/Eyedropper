# Eyedropper
A eyedropper tool! Put a picture in, click on any area of the picture to see what color it has.

# Installing 
Download the .zip file in this repository. Unzip it, and click "Eyedropper". Then it should run.

# How to Use
Press "Add Image" then the image will show up, click a area in the picture, the color picker will show you where that color lies on the color picker, along with it's hex code
